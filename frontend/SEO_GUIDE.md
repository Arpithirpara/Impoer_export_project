## 🏷️ 3. How to Change Meta Title / Description in 5 Seconds

Kisi bhi `layout.js` ya `page.js` file me sirf in lines ko edit karein:

```javascript
export const metadata = {
  title: "Aapka Naya Page Title Here",
  description: "Aapka Naya Google Description Here (150-160 characters best)",
  openGraph: {
    title: "Social Share Title Here",
    description: "Social Share Description Here",
  },
};
```
